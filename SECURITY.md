# Security Policy — 23:59, 27.07.2026

## Scope

This repository contains Atlas governance, schemas, content controls and implementation evidence. It must not contain production credentials, customer-confidential material, protected data packages, bank/accounting data or sensitive personal data.

## Reporting a security concern

Do not disclose suspected vulnerabilities, exposed secrets or confidential material in a public issue. Contact the repository owner through an established private business channel and include the affected path or commit, impact, reproduction details and any containment already performed.

## Secret or data exposure response

1. Stop affected workflows or publication paths.
2. Revoke and rotate the exposed credential outside GitHub.
3. Preserve relevant commit, workflow and access evidence.
4. Remove unsafe artifacts and remediate history where required.
5. Assess customer, contractual and GDPR notification obligations.
6. Re-enable only after validation and documented approval.

## Repository controls

Changes to workflows, governance rules, release gates, security documents and canonical records require pull-request review and recorded evidence. Repository transfer remains on hold until separately approved.
